# Rawaqan POS Desktop

نسخة Windows المحلية لنقطة البيع. واجهة التطبيق مضمّنة داخل البرنامج، وتعمل قاعدة
IndexedDB والطابور المالي دون اتصال. عند عودة الإنترنت تمر طلبات `/api` من التطبيق
إلى Render وتعمل آلية المزامنة الموجودة في POS تلقائياً.

## التطوير والبناء

من جذر المشروع:

```powershell
npm.cmd install --prefix desktop
npm.cmd run start --prefix desktop
npm.cmd run dist:win --prefix desktop
```

المثبت الناتج يوجد في `desktop/release`. اضغط **إعداد الطابعة** في شريط POS لاختيار
اسم الطابعة الذي يعرضه Windows، وتأكد من تفعيل الطباعة التلقائية وورق 80 مم.

## اختبار القبول على جهاز الكاشير

1. افتح البرنامج والإنترنت متصل، سجّل الدخول وأقرن الجهاز وافتح وردية.
2. اختر الطابعة من **إعداد الطابعة** ونفّذ طلباً تجريبياً واطبعه.
3. افصل Wi-Fi وأغلق البرنامج بالكامل ثم افتحه مجدداً.
4. افتح POS بالـPIN المحلي، أنشئ طلباً وادفع واطبع؛ يجب أن تتم الطباعة محلياً.
5. أعد الإنترنت وتأكد من وصول عداد العمليات المعلّقة إلى صفر بلا تعارضات.

لا يضع التطبيق أي مفتاح Neon على جهاز الكاشير، ولا يتصل بقاعدة البيانات مباشرة.
