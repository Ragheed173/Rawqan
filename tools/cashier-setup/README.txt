RAWAQAN POS - CASHIER SETUP

1. Copy this entire folder to the cashier computer.
2. Connect and install the thermal receipt printer.
3. Double-click Install-RawaqanPOS.cmd.
4. If the printer is not named POS-80, set the correct receipt printer as the
   Windows default printer.
5. Open Rawaqan POS only from the new desktop shortcut.
6. Sign in once, initialize offline mode, and print one test receipt.

The dedicated shortcut launches Microsoft Edge with kiosk printing enabled, so
the receipt is sent to the Windows default printer immediately after payment.
